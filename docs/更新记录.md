# 更新记录

## 手机 v140（2026-11-08 凌晨）

### 单页切换实例
- `/m/` 顶部新增「主 / rc2」按钮：点一下切换实例，选择记在本地，不用换页面/换地址
- 切到 rc.2 时自动走 `/m2/login?back=/m/` 让 nginx 种好 rc.2 的 cookie 再回来
- `/m2/` 保留为兜底入口（路径强制 rc.2）

### rc.2 接口核实
- 手机端用到的 16 个远程方法在 rc.2 上**全部存在**（含 workspace/follow 流）
- rc.2 实际缺失：`workspace/list`、`workspace/read`、`workspace/write`、`schedule/list`（手机端未使用，不影响）

## 手机 v139（2026-11-08 凌晨）

### 新增 rc.2 实例手机页（/m2/）
- 同一份 PWA 按路径识别实例：`/m/` = 主实例，`/m2/` = rc.2 实例（服务器 3081）
- 所有 API / WebSocket / 会话列表自动加 `/m2` 前缀
- rc.2 的登录 cookie 由 nginx + bridge 自动种给浏览器（`/m2/login`），没登录时先回 `/m/` 输密码
- 服务端：`/m2/m/list` → 缓存层新增 `inst=rc2` 分支（直连 3081，5 秒缓存）
- 已知限制：推送仅主实例；rc.2 旧版接口差异

## 客户端（Windows 1.5.1，2026-11-08 凌晨）

### 安全与稳定性
- 远程协助端点 `/__proxy/remote` 只接受本机主进程请求（自定义头 + Origin/Referer 校验），跨站页面无法再打开远程协助（实测无头请求 403）
- 缓存容量治理：`maxCacheMb` 真正生效（默认 4096MB），超限按最旧删到 80%；`session/page` 缓存 0→30 天；会话快照缓存超 6 小时自动清
- `proxy.log` 超 10MB 自动轮转（保留 .1）；启动时清理旧更新目录（stage/apply 各留最新 1 个）
- 多实例端口被占用时自动顺延到空闲端口
- 新增 `GET /__proxy/selfcheck`：版本 / 列表条数 / 缓存大小 / 磁盘剩余 / 退避状态

### 手机 v137
- 离线缓存 7 天过期 + 条数上限（会话 300 / 工作区 50）；长按版本号 0.9 秒清除本地离线缓存
- `deploy.sh` 增加部署后冒烟自检（校验线上 BUILD 与首页 200），并清理历史 `.broken` 残留

### 服务端
- nginx `/api/session/list` 加缓存层故障回源（upstream backup → 3080）
- `/root/dsh-web-rc2.log` 加 logrotate
- 修复 `/rc2/_dsh/token` 匿名可读 token 的漏洞（P0）

## 客户端（Windows 1.5.0，2026-11-07 夜）

### 多实例（主实例 + rc.2 实例）
- 菜单新增「实例」，可在**主实例**（19306）与 **rc.2 实例**（19306/rc2 → 服务器 3081）之间切换，Ctrl+1 / Ctrl+2
- 每个实例独立本地代理（19390 / 19392）与独立缓存目录，互不干扰
- 切到未启动的实例会自动拉起代理；「重连」只作用于当前实例
- 本地代理支持 upstream 带路径前缀（`/rc2`），请求与 WebSocket 自动加前缀
- 修复实例名含中文导致 `Invalid character in header content ["x-dsh-client"]`

## 客户端（Windows，1.4.7 → 1.4.9，2026-11-07）

### 1.4.8 会话列表增量
- `session/list` 改为「本地快照永远直出 + 按 sessionId 增量合并（新增/变化/消失/未变计数）」
- 后台刷新单飞（并发请求共享同一 Promise）+ 失败退避 30s → 60s → … → 300s
- 删掉「超 10 分钟就回落网络」的硬过期；只有本地一条快照都没有的冷启动才同步等网络
- 写操作（archive/rename/delete/fork/create）不再删磁盘快照，改为保留 + 300ms 后台对齐
- 预取（列表页/最近会话快照）复用同一份列表，启动时不再各打一次全量（省 2×100 秒）
- `/__proxy/stats` 增加 listIndexSize / listMerge / listBackoffMs / listBlockMs 等指标

### 1.4.9 修复窗口黑屏
- 本地代理连接池 `maxSockets` 8 → 64（原来是官方界面 1Hz 的 `/dsh-purge/rewind` 轮询把 8 个 socket 占满，`GET /` 排队 >90 秒，窗口只剩背景色）
- 普通 GET 统一 30 秒超时；`/plugins/events`、`/agent`、`/push/`、`/api/remote.mux` 等长连接不设超时
- `did-fail-load` 自动重试页面加载（黑屏时 1.5 秒后自动重载）
