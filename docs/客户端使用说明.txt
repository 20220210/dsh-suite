DSH 桌面版 v1.2.1（绿色版 · 会话切换秒开 · 自动升级）

一、这一版是什么
  绿色版：解压到任意目录（U 盘也行），双击 "DSH Desktop.exe" 就能用，
  不写注册表、不需要安装程序、不需要管理员权限。
  首次启动会自动在桌面创建快捷方式；以后从桌面直接打开即可。
  文件夹可以随便挪动，挪动后如果桌面图标失效：
  菜单「帮助 → 创建桌面快捷方式」重建一次。

二、为什么快
  · 会话历史走 WebSocket，本程序在本地代理里缓存了「会话打开快照」：
    第一次进某个会话仍从服务器拉取，之后再切回直接读本地，基本瞬间出现；
  · 启动后后台预取最近 5 个会话的快照（约 1MB），常用会话第一次切就是本地；
  · 打开会话后，新回复/新事件仍然实时从服务器来，不会丢消息；
  · 正在生成回复的会话缓存会过期，会自动改走服务器（慢一次），这是正常的。

三、自动升级
  · 启动约 20 秒后自动检查一次新版本，之后每 6 小时检查一次；
  · 也可以在菜单「帮助 → 检查更新…」手动检查；
  · 发现新版本会弹窗，点「立即升级」→ 后台下载 → 校验 → 自动重启两次进入新版本；
  · 常用升级包只包含程序本体（几百 KB ~ 几 MB），不需要重新下载 150MB 的整包；
    只有底层 Electron 运行时升级时才会下载完整包，程序会自动判断；
  · 「跳过此版本」会记住你的选择，下次不再打扰（可在配置里改 update.skipVersion）。

四、配置（菜单：文件 → 打开配置目录）
  config.json 关键项：
  - upstream       服务器地址（https://dsh.example.com:19306）
  - basicUser / basicPass   nginx 认证（已填好）
  - token          DSH 登录令牌（服务器重启后若提示未登录，把新 token 填这里）
  - prefetchFollow 启动时预取最近几个会话的快照（默认 5，设 0 关闭）
  - prefetch       是否预取所有会话的 HTTP 首页（默认 false，省流量）
  - maxCacheMb     本地缓存上限（MB，默认 4096）
  - update.manifests       版本清单地址列表（按顺序尝试，第一个成功就用）
  - update.checkIntervalHours  自动检查间隔（小时）
  - update.skipVersion     被跳过的版本号
  改完配置后重启客户端生效。

五、缓存、日志
  菜单「文件 → 打开日志」：proxy.log、update.log
  缓存目录：%LOCALAPPDATA%\dsh-client\cache
  升级下载目录：%APPDATA%\dsh-desktop\updates（升级完成后自动清理）
  想清空缓存：退出客户端后删掉 cache 目录即可。

六、安全
  只读缓存，不会修改服务器上的会话；本地缓存含对话内容（压缩明文），
  只存在你自己电脑上，删目录即清空。连接仍是 HTTPS + 服务器认证。
